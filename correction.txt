# Opezee License Management System

## Correction & Enhancement Tasks

### 1. Dashboard — Estimated Time: 5 Minutes

* Display all license information using **card-based visualization**.
* Remove the existing **license data table** from the Dashboard.
* Add a **Settings** option at the bottom of the sidebar.
* Add two new sidebar options:

  * **Products**
  * **Clients**

### 2. License Management — Estimated Time: 20 Minutes

* Change the table column **Created Date** to **Start Date**.
* In the **Action** column:

  * Remove the Edit option.
  * Add **View** and **Delete** icons.
* Make the **View** option editable:

  * Open the client's license details in a popup.
  * Allow the admin to edit and update the client information from the popup.
* Rename the **Email** column to **User Name**.
* Update the license popup to provide predefined expiry duration options:

  * 1 Month
  * 3 Months
  * 6 Months
  * 1 Year
* Add a **Custom Date** option to allow the admin to manually select:

  * Start Date
  * Expiry Date
* Rename **Client Email** to **Client User ID** in the license popup.

### 3. Product Management — Estimated Time: 20 Minutes

* Create a **Product Management** page with a table displaying all added products.
* Add an **Add Product** button.
* The Add Product form should contain only two fields:

  * Product Name
  * Product Description

### 4. Settings — Estimated Time: 2 Hours

* Add a **Dark Mode / Light Mode** toggle.
* Add an option for the admin to **change the login password**.
* Add functionality to configure email IDs:

  * Add a new email ID.
  * Set one email ID as the **default email ID**.

### 5. Admin Login Page — Estimated Time: 1 Hour

* Create a dedicated **Admin Login** page to secure access to the License Management System.
* Login should require:

  * Email
  * Password
* Implement **dynamic credential validation** through the backend/API.
* Allow access to the License Management System only after successful authentication.

### 6. APIs for Client Application Integration — Estimated Time: 3 Hours

* Create an API to **validate/check the license key** from the client application.
* Create an API for **automatic license-key synchronization**, with synchronization/checking performed continuously at a **1-hour interval**.
* Create an API to **validate admin login credentials**.

### Estimated Total Effort

**Approximately 6 hours 45 minutes**

These changes cover the required UI corrections, license management improvements, product management, admin settings, authentication, and APIs required for integration with the client application.
